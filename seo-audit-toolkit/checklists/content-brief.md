# Content Brief

Fill this in before a page is commissioned. Scoring a finished draft is the most expensive
point at which to discover the topic was wrong.

## Target

- **Primary query:** [one, not several]
- **Search intent:** informational / commercial / transactional / navigational
- **Who is searching this and what do they want in the first 30 seconds:**
- **Assigned URL:** [one page owns this query, and only this page]

## Cannibalization check

- [ ] Existing inventory searched for pages already targeting this query or a close variant
- [ ] If one exists, the decision is recorded: update the existing page, or differentiate
      this one explicitly. Do not publish a second page competing with your own

## Competitive baseline

- [ ] Top 5 ranking results reviewed
- **What all of them cover:** [the table stakes]
- **What none of them cover:** [the reason this page has a right to exist]
- **Format that ranks:** [guide / comparison / tool / listicle / definition]
- **Depth needed to compete:** [approximate, based on what actually ranks]

## Requirements

- **Must answer:** [the specific questions, listed]
- **Must include:** [original data, first-hand experience, examples, screenshots]
- **Must not include:** [claims that need approval, regulated language, unverifiable stats]
- **Internal links out:** [3-5 existing relevant pages]
- **Internal links in:** [existing pages that will link to this once published]

## Metadata

- **Title:** [written for how people search, not for internal taxonomy]
- **Meta description:** [written, not left for the search engine to generate]
- **H1:** [distinct from the title where useful]
- **Author:** [a real named person with relevant experience, not a default value]

## Acceptance

- [ ] Answers the target query fully above the fold
- [ ] Adds something the top results do not have
- [ ] Every factual claim has a source
- [ ] Internal links in both directions in place before publication
- [ ] Metadata written, not auto-generated
