# Monthly Report

## Before writing

- [ ] Date window fixed and stated, and identical across every metric in the report
- [ ] Comparison window chosen deliberately — previous period, or same period last year —
      and stated
- [ ] All data pulled fresh. Nothing reused from last month's file
- [ ] Any known data gaps or collection changes in the window noted up front

## Contents

- [ ] Branded and non-branded traffic reported separately. Never one blended organic number
- [ ] Clicks, impressions, CTR, and average position each shown, not just clicks
- [ ] Movement explained by mechanism, not just described. A click drop at stable positions
      is a CTR problem, not a ranking problem, and the fixes are unrelated
- [ ] Conversions or downstream outcomes included where the data exists, marked as absent
      where it does not
- [ ] Work completed this period listed, each item verified as actually live
- [ ] Work planned next period listed, with dependencies
- [ ] Open decisions needed from stakeholders listed separately from work items, so they do
      not get lost inside a status update

## Verification

- [ ] Every number re-derived from the source at the stated window
- [ ] Totals reconcile against their rows
- [ ] Nothing described as complete without a production check
- [ ] Carried-forward wording from last month diffed and re-verified
- [ ] `pre-delivery-review.md` run in full
